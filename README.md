# 🍽️ Mess Management System

A modern **Mess Management System** built with **Google Apps Script + Google Sheets** for managing mess operations digitally.

## ✨ Features

* 👨‍💼 Admin Dashboard
* 👨‍🍳 Manager Dashboard
* 👨‍🎓 Student Dashboard
* 🍛 Daily & Weekly Menu
* 🍽️ Meal Attendance
* 💰 Billing & Payments
* 📦 Inventory Management
* 💸 Expense Management
* 📝 Complaint Management
* 📢 Notices
* 📊 Reports & Analytics
* 📱 Responsive Design

## 🛠️ Technology

* Google Apps Script
* Google Sheets
* HTML5
* CSS3
* Vanilla JavaScript
* Chart.js
* Font Awesome

## 🏗️ Architecture

```text id="gkqv2h"
Frontend
   ↓
Google Apps Script
   ↓
Google Sheets Database
```

## 👥 User Roles

**Admin** — Complete system management

**Manager** — Menu, attendance, inventory, expenses & complaints

**Student** — Menu, attendance, bills, payments & complaints

## 🚀 Deployment

1. Create Google Sheet
2. Open **Extensions → Apps Script**
3. Add `Code.gs`
4. Add `Index.html`
5. Run `initializeDatabase()`
6. Deploy as **Web App**
7. Open the generated `/exec` URL
